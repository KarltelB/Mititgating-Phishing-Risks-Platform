## Overview

This project was developed as part of my final-year BSc (Hons) Cyber Security degree at De Montfort University.

The application is an interactive web-based cybersecurity awareness platform designed to educate stadium fans about phishing attacks, social engineering techniques, and ticket-related scams. The platform combines educational content with interactive exercises and quizzes to help users recognise common phishing tactics and make safer decisions when purchasing tickets or interacting with online fan engagement platforms.

The project demonstrates the importance of user-focused cybersecurity education by applying secure design principles to improve awareness and reduce the likelihood of phishing attacks.

**Features**

- Interactive learning modules covering phishing awareness
- Social engineering education with realistic attack scenarios
- Stadium ticket scam awareness
- Interactive knowledge quizzes with instant feedback
- Automatic quiz result delivery using EmailJS
- Responsive single-page web application
- Modern, user-friendly interface
- Educational content based on current phishing techniques and cybersecurity best practices

**Learning Objectives**

The platform helps users to:

- Understand how phishing attacks work
- Recognise common phishing indicators
- Identify suspicious emails, websites, and messages
